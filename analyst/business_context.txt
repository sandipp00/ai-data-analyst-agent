- Revenue = SUM(order_items.quantity * order_items.unit_price), counting only orders whose status is not 'cancelled', unless the user says otherwise.
- Profit = SUM(order_items.quantity * (order_items.unit_price - products.cost)) with the same status filter.
- "Customers" with no further qualifier means rows in the customers table; "active customers" are those with at least one non-cancelled order in the period.
- Today's date is available via CURRENT_DATE; "last month" means the previous calendar month.
- Order status values: completed, shipped, cancelled, returned. "Returned" orders still count toward revenue unless the user asks for net revenue; "return rate" = share of orders with status 'returned'. "Cancellation rate" = share of orders with status 'cancelled' (use all orders as the denominator). Rates are always counted in orders, never line items: when broken down by product or category, use COUNT(DISTINCT orders.id) for both numerator and denominator (an order counts toward each category it contains).
- Customer segments are consumer, small_business and enterprise. Countries are full English names (e.g. 'United States').
- Margin % = (unit_price - cost) / unit_price. Average order value (AOV) = revenue per order, aggregated per order before averaging.
- When ranking ("top N"), return at most N rows. For time series, include periods in chronological order.
- "Last N months" / "past N months" includes the current (partial) month: use the current month and the N-1 months before it. "Return" always means status = 'returned', never 'cancelled'.
- "Last quarter" means the previous calendar quarter. "Last N days" means order_date >= CURRENT_DATE - N (today included).
- "Units sold" = SUM(order_items.quantity) over non-cancelled orders. "Order value" is revenue per order (non-cancelled orders only), as for AOV.
- "Repeat customers" have 2+ non-cancelled orders; "repeat customer rate" = repeat customers / customers with at least one non-cancelled order.
- Return rates and shares as fractions between 0 and 1 (not multiplied by 100) unless the user asks for a percentage.
